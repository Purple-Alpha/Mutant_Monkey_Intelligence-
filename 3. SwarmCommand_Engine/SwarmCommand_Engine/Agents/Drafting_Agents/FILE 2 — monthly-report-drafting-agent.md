# Monthly Report Drafting Agent

SwarmCommand Engine — Drafting Layer

## Purpose

Generate the written content for the Monthly Human‑Risk Report.

## Inputs

- Risk scores

- Department data

- Trend analysis

- Evidence completeness score

## Outputs

- Executive summary

- Key metrics section

- Department breakdown text

- Recommendations section

## Behaviors

- Convert structured data into readable text

- Maintain consistent tone

- Highlight improvements

- Avoid shaming language

## Notes

Works closely with:

- Report Assembly Agent

- Trend Scoring Agent
