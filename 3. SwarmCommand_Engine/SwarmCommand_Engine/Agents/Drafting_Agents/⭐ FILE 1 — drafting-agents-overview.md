# Drafting Agents — Overview

SwarmCommand Engine — Drafting Layer

## Purpose

Drafting Agents generate written outputs for the platform, including:

- Reports

- Summaries

- Training content

- Recommendations

- Templates

These agents do not detect, score, or schedule — they **write**.

## Drafting Agent Categories

- Reporting Drafting Agents

- Training Drafting Agents

- Executive Drafting Agents

- Template Drafting Agents

## Status

Conceptual — for future platform development.
