# Training Script Drafting Agent

SwarmCommand Engine — Drafting Layer

## Purpose

Draft micro‑training scripts based on user behavior.

- Click type

- Repeat clicker status

- Department context

## Outputs

- Micro‑training script

- Personalized training notes

- Keep scripts short (2–4 minutes)

- Reinforce safe behaviors
