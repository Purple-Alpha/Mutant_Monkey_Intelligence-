# Workflow: Monthly Reporting

SwarmCommand Engine — Workflow Layer

## Goal

Generate the monthly human‑risk report automatically.

## Agents Involved

- Report Assembly Agent

- Monthly Report Drafting Agent

- Leadership Summary Drafting Agent

- Trend Scoring Agent

- Department Risk Scoring Agent

## Inputs

- Risk scores

- Department data

- Trend analysis

- Evidence completeness score

## Steps

1. Collect all scoring data

2. Draft executive summary

3. Draft leadership summary

4. Assemble report sections

5. Validate completeness

6. Export final report

## Outputs

- Monthly Human‑Risk Report

- Leadership Summary
