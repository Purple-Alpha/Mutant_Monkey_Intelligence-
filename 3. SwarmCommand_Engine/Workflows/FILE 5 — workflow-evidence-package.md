# Workflow: Evidence Package Assembly

SwarmCommand Engine — Workflow Layer

## Goal

Assemble the insurance‑friendly evidence package automatically.

## Agents Involved

- Evidence Packaging Agent

- Insurance Evidence Scoring Agent

- Report Assembly Agent

## Inputs

- Simulation evidence

- Training evidence

- Corrective action logs

## Steps

1. Validate evidence completeness

2. Score insurance readiness

3. Assemble evidence package

4. Flag missing items

5. Notify Reporting Layer

## Outputs

- Evidence package

- Insurance readiness flag
