# Workflow: Monthly Phishing Simulation

SwarmCommand Engine — Workflow Layer

## Goal

Automatically run a monthly phishing simulation for each client.

## Agents Involved

- Simulation Scheduler Agent

- Template Selector Agent

- Campaign Optimizer Agent

- Training Delivery Agent

## Inputs

- Client schedule

- Template history

- Department risk

- Repeat clicker data

## Steps

1. Scheduler selects delivery window

2. Template Selector chooses template

3. Campaign Optimizer adjusts difficulty

4. Simulation is delivered

5. Click data is collected

6. Training Delivery Agent assigns micro‑training

## Outputs

- Simulation results

- Training assignments

- Updated risk data
