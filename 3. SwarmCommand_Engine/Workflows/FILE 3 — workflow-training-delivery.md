# Workflow: Training Delivery

SwarmCommand Engine — Workflow Layer

## Goal

Deliver micro‑training to employees who clicked during a simulation.

## Agents Involved

- Training Delivery Agent

- Training Script Drafting Agent

- Repeat Clicker Scoring Agent

## Inputs

- Clicker list

- Training module library

- Repeat clicker status

## Steps

1. Identify clickers

2. Score repeat clickers

3. Draft personalized training script

4. Deliver training

5. Track completion

6. Escalate repeat offenders

## Outputs

- Training completion data

- Updated risk scores
