# Detection Sandbox — Overview

SwarmCommand Engine — Experimental Zone

## Purpose

This sandbox is used to prototype and test early detection logic for:

- Phishing pattern recognition

- Email feature scoring

- Risk signal extraction

- AI‑generated lure detection

- Executive impersonation markers

These experiments are **not production‑ready** and should not be used in client environments.

## Goals

- Explore lightweight detection heuristics

- Test agent‑based scoring logic

- Validate early signals before building full agents

- Document findings for future SwarmCommand modules

## Status

Active — ongoing experiments and prototypes.
