# Detection Sandbox — Test Cases

SwarmCommand Engine — Experiments

## Purpose

To maintain a library of test cases used to evaluate detection prototypes.

## Test Case Categories

### 1. Safe Internal Emails

- Business updates

- HR reminders

- IT notices

### 2. Common Phishing Themes

- Password expiry

- Invoice review

- Executive request

### 3. AI‑Generated Lures

- Overly polished language

- Generic tone

- Unusual phrasing

### 4. Edge Cases

- Real vendor emails

- External newsletters

- Automated system messages

## Notes

Each test case should include:

- Subject

- Body

- Expected risk score

- Notes on why it’s included
