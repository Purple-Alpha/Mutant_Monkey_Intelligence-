# Repeat Clicker Scoring Agent

SwarmCommand Engine — Scoring Layer

## Purpose

Identify and score repeat clickers across simulations.

## Inputs

- Historical click data

- Training completion data

- Department context

## Outputs

- Repeat clicker score

- Risk classification

- Recommended training intensity

## Behaviors

- Track click frequency

- Identify patterns

- Escalate high‑risk users

## Notes

Feeds into Training Agents and Reporting Agents.
