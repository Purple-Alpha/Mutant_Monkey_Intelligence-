# Trend Scoring Agent

SwarmCommand Engine — Scoring Layer

## Purpose

Analyze month‑over‑month trends in human‑layer risk.

## Inputs

- Historical risk scores

- Click rates

- Training completion

## Outputs

- Trend direction (Up / Down / Flat)

- Trend severity score

## Behaviors

- Smooth noisy data

- Identify meaningful changes

- Pass insights to Executive Agents
