# Operations Playbook

## Daily
- Check inbox
- Review client requests
- Check simulation queue
- Log urgent follow-ups

## Weekly
- Review upcoming campaigns
- Prepare reports
- Review evidence packages
- Update client notes

## Monthly
- Deliver simulations
- Send micro-training
- Generate leadership reports
- Package evidence
- Review renewal or upsell opportunities

## Operating Standard
Every operational activity should make client delivery simpler, clearer, or more repeatable.
