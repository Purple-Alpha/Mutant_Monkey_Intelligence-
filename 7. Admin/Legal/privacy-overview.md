# Privacy Overview

## Principles
- Canadian data residency
- Minimal data collection
- No unnecessary retention
- Use employee data only for simulation, training, and reporting
- Delete client data upon request or termination

## Data Types
- Employee names
- Employee email addresses
- Department or role data when provided
- Simulation activity
- Training completion status

## Boundaries
NorthStar does not request passwords, access inboxes, harvest credentials, or collect sensitive employee personal information beyond what is required for service delivery.
