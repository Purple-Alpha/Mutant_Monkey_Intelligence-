# Business Operations Guide
NorthStar Security - Operational Playbook

## 1. Purpose of This Guide
This guide explains how to run NorthStar Security operationally, day-to-day, week-to-week, and month-to-month.

It covers:
- Service delivery
- Reporting
- Training
- Client management
- Evidence handling
- Renewal workflow

This is the operator manual and working project blueprint for the business.

---

# 2. Core Operating Rhythm

## Daily
- Check the simulation inbox for client replies.
- Review any click notifications.
- Confirm training completions.
- Update client notes if anything relevant happens.

## Weekly
- Review all active clients.
- Ensure training reminders have gone out.
- Check for overdue evidence.
- Update the internal decisions log if needed.

## Monthly
- Deliver simulation.
- Process click data.
- Assign micro-training.
- Generate monthly report.
- Generate leadership summary.
- Package evidence.
- Send report and evidence to client.
- Update renewal status.

---

# 3. The NorthStar Service Model

## 3.1 What You Deliver
NorthStar delivers four things every month:

1. Phishing Simulation
2. Micro-Training for Clickers
3. Monthly Human-Risk Report
4. Leadership Evidence Package

Everything else supports these four pillars.

---

# 4. Monthly Delivery Workflow

This is the exact sequence to follow each month.

## Step 1 - Run the Simulation
- Choose template.
- Deliver to client list.
- Monitor delivery.
- Collect click data.

Tools used:
- Simulation templates
- Delivery engine

## Step 2 - Process Click Data
For each click:
- Identify user.
- Identify department.
- Mark repeat clickers.
- Log click in client notes.

Outputs:
- Click list
- Repeat clicker list
- Department breakdown

## Step 3 - Assign Micro-Training
For each clicker:
- Assign training module.
- Send training link.
- Track completion.
- Send reminders.

Outputs:
- Training completion data
- Repeat clicker escalation list

## Step 4 - Generate Monthly Report
Use:
- report-cover-page.md
- leadership-summary-template.md
- report-notes-internal.md

Sections:
1. Executive Summary
2. Key Metrics
3. Department Breakdown
4. Risk Score
5. Simulation Summary
6. Training Summary
7. Recommendations
8. Evidence Package

## Step 5 - Generate Evidence Package
Use:
- evidence-package-cover.md

Include:
- Simulation evidence
- Training evidence
- Corrective action logs

This is what insurers care about.

## Step 6 - Deliver to Client
Send:
- Monthly report as PDF or Markdown
- Evidence package
- Leadership summary

Follow up:
- Ask if they want a 10-minute walkthrough.
- Log any feedback.

# 5. Client Management

## 5.1 Onboarding
Use the `Client_Template` folder.

Steps:
- Create new folder from template.
- Add client contacts.
- Add simulation schedule.
- Add training preferences.
- Add any special notes.

## 5.2 Client Notes
Every client has a `client-notes.md` file.

Update it with:
- Key contacts
- Risk areas
- Repeat clickers
- Special requests
- Renewal status

## 5.3 Renewal Workflow
Run this every 90 days:

1. Review last 3 months of reports.
2. Review evidence completeness.
3. Prepare renewal summary.
4. Send renewal email.
5. Update renewal status.

# 6. Quality Standards

## Tone
- Plain-English
- No jargon
- No shaming
- Focus on improvement
- Highlight wins

## Reporting
- Always double-check names.
- Always verify click counts.
- Always verify training completion.
- Always check department names.

## Evidence
- Must be complete.
- Must be accurate.
- Must be stored in Canada.
- Must be retained for 12 months.
