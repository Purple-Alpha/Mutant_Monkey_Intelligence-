# Internal Report Notes

NorthStar Security — For Internal Use Only

## Purpose

This file helps maintain consistency across all client reports.


## Tone Guidelines

- Plain‑English

- No jargon

- No shaming

- Focus on improvement

- Highlight wins


## Data to Double‑Check Before Sending

- Client name

- Month

- Employee count

- Click numbers

- Training completion

- Repeat clickers

- Department names


## Common Phrases to Use

- “Your team showed improvement in…”

- “We recommend reinforcing…”

- “This month’s simulation focused on…”

- “Your insurer will expect evidence of…”


## Common Phrases to Avoid

- “Your employees failed”

- “This was a major issue”

- “High‑risk individuals” (use “repeat clickers”)
