## **Conventions**

- Root-level working files use `Snake_Case_With_Capitals.md`.
- Notion-export files must not keep `# ` prefixes; preserve them as `*_Notion_Export.md` only when a richer canonical file already exists.
- Offer sheets are versioned in the title (e.g. `Version 1.0`).
- Client‑signed templates live in `Client_Documents/`.
- Outbound copy lives in `Outreach Cold_Email_Sequence/` — one file per sequence, dated.
- Final client‑facing assets must pass the **plain‑English / no jargon** check.
