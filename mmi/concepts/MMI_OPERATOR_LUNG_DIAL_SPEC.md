## 2. Two dials (operator original intent)

These are **independent controls**. They are **not** the same as “Light / Normal / Deep breath” post-verdict tiers in the June 9 concept doc — those may remain as a **separate** protection-depth axis if still useful.

### Dial 1 — Deal path (time-pressure override)

**Problem:** Legitimate business email flagged or gated (e.g. Microsoft Defender). A real deal has a deadline (example: one hour). Evidence says **not fraud**.

**Lung dial action:** Allow the deal path to proceed with **documented human override** — tech reads evidence chain, releases with name and reason logged.

**Not:** silent bypass, unaudited release, or “trust the model.”

**Canonical scenario (from operator):** $50k deal, Defender down or wrong, evidence confirms known vendor — deal closes because the organism provides an accountable escape hatch Microsoft does not.

### Dial 2 — Swarm scale (attack inflation factor)

**Problem:** Coordinated attack or sustained pressure on a tenant.

**Lung dial action:** Increase **how many governed copies** of existing specialist agents run in parallel (example metaphor: 70 agent **types** at baseline → 700 or 7000 **effective workers** as copies, not new species).

**Not:** unbounded spawn, self-fission in the field, or grandchildren without Matt sign-off.

**When attack ends:** **Exhale** — copies retire; agents return to baseline; immune system verifies teardown.

**Purple alignment:** Inflated parallel investigation + friction + attacker-cost memory makes fraud **expensive**, not merely “blocked.”
