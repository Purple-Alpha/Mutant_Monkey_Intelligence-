## 2. KEEP — Dynamic topology morphing (graph evolution)

### External idea

Graph expands by adding communication edges as complexity rises; prunes edges when sub-tasks resolve (DyTopo, MiroFlow-class research).

### Governed translation (Mutant Monkey)

**Federation boundary:** Opted-in MSP pool publishes **Pathogen Signature Pulses** — directed warning edges with TTL. Edges **expire** (deflate) per IFM-D6. Not raw data edges; HMAC fingerprints only.

**Tenant interior:** Commander `#1` assembles **caller-declared agent graphs** per case — variable participants, fixed spine. Layer 5 challenge adds temporary corroboration paths.

### Useful borrowings

- **Semantic edge activation** → mesh trust tier + `MeshResponsePermission` (already in mesh contract §9)
- **Structural prune on resolution** → pulse TTL + automatic exhale (LF-D8) + mesh expiry
- **Research input for mesh P1 sandbox** — visualize nodes (tenant cells), edges (active pulses), prune on `expires_at`

### Hard limits (do not import)

- Agents autonomously creating permanent edges without registry + §11
- Cross-tenant graph morphing that carries class-B/C fields (Guardrail 11)
- Replacing Commander/RA with emergent topology

## 3. KEEP — Context-folding (fluid memory scaling) — tenant-scoped only

### External idea

Scale cognitive volume by pouring context into skeletal shells; flush to cold storage when done — avoid minting new agents.

### Governed translation (Mutant Monkey)

**Already adjacent on disk:**

- Layer 0 knowledge agents `#72–77` — brief-only, immutable briefings (no blackboard writes)
- Blackboard contributions per case — elastic **evidence context**, not new agent types
- Load Fission `#90`/`#103` — same agent **type**, more **parallel copies** (Dial 2 metaphor)

**Useful borrowings**

- Prefer **context swell + copies** over net-new agent types where LF-D4 applies
- Token Usage Tracker `#71` for surge attribution when context/copies expand
- Case-end **context discard** — in-memory DER posture; no cross-case tenant bleed

### Hard limits (do not import)

- Cross-tenant “pour” of semantic vectors (violates IFM-D9, Privacy Filter posture)
- Context flush that destroys audit trail or evidence chain
- Shell agents without scoreboard row + contract lifecycle

## 4. DISCARD — Stigmergy / pheromone routing

### External idea

No central brain; agents coordinate via environmental trails (database pheromones); swarm inflates organically around stimulus.

### Why discarded for Mutant Monkey

|---|---|

| Operator exit | Safe-Stop Matt-only; not emergent decay-only |

### Optional metaphor only (not architecture)

- Shadow sensors as **local** weak trails inside one tenant — not global stigmergy
