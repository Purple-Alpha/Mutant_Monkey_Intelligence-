# Dashboard Guide  
NorthStar Security — Monthly Reporting Dashboard

## Purpose
This guide explains how to use the internal dashboard spreadsheet to track monthly phishing simulation results.

## Dashboard Sections
### 1. Overview
- Total emails sent  
- Total clicks  
- Click rate  
- Repeat clickers  

### 2. Department Breakdown
- Click rate by department  
- High‑risk departments highlighted in red  

### 3. Trend Line
- Month‑over‑month click rate  
- Trend arrows (up/down/flat)  

### 4. Training Completion
- Completion percentage  
- Repeat offenders  

### 5. Leadership Summary
- Key insights  
- Recommended actions  

## Usage Notes
- Update data monthly  
- Keep historical data for insurance  
- Export PDF for leadership if needed
