# Evidence Collection Guide  
NorthStar Security — Insurance‑Friendly Documentation

## Purpose
To ensure clients have the evidence required for cyber insurance renewals and audits.

## Evidence Types
### 1. Simulation Evidence
- Simulation summary  
- Template used  
- Delivery date  
- Number of recipients  
- Click results  

### 2. Training Evidence
- Training module delivered  
- Completion list  
- Completion percentage  

### 3. Corrective Action Evidence
- Repeat clicker follow‑up  
- Additional training (if any)  
- Leadership review notes  

### 4. Monthly Report
- Risk score  
- Department breakdown  
- Recommendations  

## Storage Requirements
- Store all evidence in the client’s folder  
- Keep 12 months of history  
- Delete upon client request
