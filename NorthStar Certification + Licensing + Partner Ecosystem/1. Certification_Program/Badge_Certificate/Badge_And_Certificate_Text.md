# Certification Badge and Certificate Text

## Badge Text
**NorthStar Certified Operator (NSCO)**

Issued by NorthStar Security

Valid for 12 months

## Certificate Text
This certifies that **[Name]** has successfully completed the **NorthStar Certified Operator (NSCO)** program and demonstrated proficiency in delivering monthly phishing simulations, micro-training, human-risk reporting, and evidence package assembly.

Issued by NorthStar Security

Valid for 12 months

## Certificate Fields
- Candidate name
- Certification level
- Issue date
- Expiry date
- Certificate ID
- Issuer signature

## Layout Notes
- Use NorthStar branding.
- Keep the layout clean and professional.
- Include the certificate ID and expiry date clearly.
- Avoid implying government, university, or third-party accreditation unless formally obtained.
